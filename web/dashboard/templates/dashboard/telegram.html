El destino se lee de TELEGRAM_BARGAIN_CHAT_ID en tu configuración privada.

Cómo se calcula el valor justo

Se combinan tres referencias: histórico reciente de subastas/ofertas públicas, equivalencia Limited → Rare y suelo alternativo (sin contar la carta candidata). Si existe suelo alternativo, el valor final nunca lo supera.

Fórmula: valor = media ponderada(histórico, equivalencia, suelo); un dato débil recibe menos peso. Pon 0 para ignorar una referencia.
